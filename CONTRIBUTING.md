# Contributing to FinWorldModel

FinWorldModel (Financial World Model / FinancialWorldModel)
is a proprietary, source-visible financial research and
software project maintained by David M. Wadsworth.

The repository is publicly accessible for inspection,
technical reference, and academic citation.

Public access does not grant general permission to reuse,
modify, redistribute, or commercially exploit Project materials.

## 1. Contribution Policy

External contributions are considered individually.

Prospective contributors should contact the Maintainer before
undertaking substantial work intended for inclusion in the Project.

All contributions are subject to technical, research, and
intellectual property review.

The Maintainer may accept, reject, defer, or request changes
to any proposed contribution.

## 2. Contributor Ownership

Contributors retain copyright ownership of their original
contributions.

The Project does not require contributors to assign ownership
of their original work to the Maintainer.

However, accepted contributions require an executed
Contributor License Agreement (CLA).

The CLA grants the Maintainer the rights necessary to
incorporate, maintain, modify, distribute, sublicense,
and commercially license accepted contributions as part
of the Project.

## 3. Acceptance Requirements

Before a contribution is accepted:

1. The contribution must undergo appropriate review.
2. Third-party dependencies and externally licensed materials
   must be disclosed.
3. The Contributor must execute the applicable CLA.
4. The Maintainer must explicitly accept the contribution.

Submitting a pull request does not automatically grant
licensing rights or establish acceptance.

## 4. Research Contributions

Research contributions must:

- Include appropriate citations and references.
- Identify externally authored material.
- Distinguish original findings from published findings.
- Disclose relevant datasets and their usage restrictions.
- Include methodology and reproducibility information
  where reasonably applicable.

Contributors must not submit copyrighted research or
publisher-restricted material without appropriate rights.

## 5. Code Contributions

Code contributions should:

- Follow the existing project architecture.
- Include appropriate tests where applicable.
- Document new dependencies.
- Identify external code and licensing requirements.
- Avoid introducing dependencies with incompatible
  licensing restrictions without prior approval.

## 6. Third-Party Materials

Contributors must disclose third-party code, research,
datasets, documentation, and other externally owned
materials included in their submissions.

Contributors must have the authority to grant the rights
required by the CLA.

## 7. Contributor Agreement

The Contributor License Agreement is located at:

[CONTRIBUTOR_LICENSE_AGREEMENT.md](CONTRIBUTOR_LICENSE_AGREEMENT.md)

A completed agreement is required before acceptance of
a contribution.

## 8. Maintainer Authority

The Maintainer retains discretion over:

- Project direction and architecture.
- Research priorities and methodology.
- Contribution acceptance.
- Release schedules.
- Licensing and commercial distribution.
- Project documentation and governance.
