# Security Policy

**Project:** Financial World Model
**Repository:** FinWorldModel
**Maintainer:** David M. Wadsworth

## 1. Supported Versions

Security issues should be reported against the latest
available Project version or the current development
branch.

Older versions may not receive security updates.

## 2. Reporting a Vulnerability

Please do not disclose suspected security vulnerabilities
through public GitHub issues or public pull requests.

Use GitHub's private vulnerability reporting feature
for this repository, if enabled.

Alternatively, contact:

david.wadsworth80@gmail.com

Include:

- A description of the suspected vulnerability.
- Affected components or versions.
- Reproduction steps, where possible.
- Potential impact.
- Any suggested mitigation.

Do not include passwords, API keys, access tokens,
private financial data, or other sensitive information
in vulnerability reports.

## 3. Handling Reports

The Maintainer will make reasonable efforts to:

1. Acknowledge receipt of a report.
2. Assess its validity and potential impact.
3. Investigate and develop an appropriate response.
4. Coordinate disclosure where appropriate.
5. Document relevant security fixes.

Response times may vary depending on severity,
complexity, and available resources.

## 4. Disclosure

Please allow reasonable time for investigation and
remediation before publicly disclosing an unresolved
vulnerability.

The Maintainer may coordinate a disclosure timeline
with the reporter.

## 5. Scope

This policy covers vulnerabilities affecting the
FinWorldModel Project and its maintained components.

It does not authorize security testing against third-party
services, financial data providers, or infrastructure
without their explicit permission.
